# Personal Expense Tracker with CSV

## Project Overview
The Personal Expense Tracker is a Python-based application that helps users record, manage, and analyze their daily expenses.

## Features
- Add new expenses.
- View all recorded expenses.
- Filter expenses by category.
- Calculate category-wise expense totals.
- Store expense records permanently in a CSV file.
- Validate dates and expense amounts.

## Technologies Used
- Python
- CSV Module
- OS Module
- Datetime Module

## Project Files
- `expense_tracker.py` – Main Python application.
- `expenses.csv` – Stores expense records.

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python expense_tracker.py
```

## Sample Categories
- Food
- Travel
- Shopping
- Bills
- Other
